# Engineering Standards

本目录是项目的代码标准上下文。任何 AI 角色改代码前必须读取相关规范。

当前标准：

- `backend-coding-standard.md`
- `frontend-coding-standard.md`
- `api-contract-standard.md`
- `database-standard.md`
- `permission-standard.md`
- `testing-standard.md`
- `documentation-maintenance-standard.md`

原则：规范必须服务当前项目，不为了形式引入过重框架。

数据库相关开发还必须读取：

- `docs/数据库设计说明书_v1(1).docx`
- `docs/context/requirements/database-design.md`

后续新增表、字段、关系和字典必须优先按数据库设计说明书执行。
