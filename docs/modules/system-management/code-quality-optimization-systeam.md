# 系统管理模块代码打磨记录

## 范围与边界

- 覆盖用户、角色、菜单、字典、配置、审计日志、通知和个人中心。
- 保持现有 HTTP 路径、请求字段、响应结构和已落地业务流程不变。
- 仅修复非法输入、权限显示缺口、事务一致性和重复查询风险。

## 已完成优化

- 用户分页接口改为批量查询用户角色关系和角色信息，移除逐用户查询角色的 N+1 路径。
- 菜单祖先节点补齐改为一次性加载菜单映射；新增父菜单存在性、当前节点自身和子节点循环校验。
- 通知“全部已读”和“清空已读”改为单条批量更新/删除，保留原有操作日志内容。
- 字典类型改名时，字典项编码改为批量更新；用户、角色、菜单、字典、配置、通知的写操作与审计日志纳入事务边界。
- 权限规则改为静态只读集合，避免请求处理期间重复创建规则对象。
- 用户、角色页面的新增、编辑、状态、删除、重置密码和授权按钮与后端权限编码一致；后端仍作为最终权限边界。
- 配置、字典、菜单的 DTO 补充了枚举、长度与数值边界校验。

## 验证结果

- 后端：`scripts/build-api.ps1` 通过。
- 前端：`scripts/build-web.ps1` 通过。
- 接口：健康检查、管理员登录、当前用户、用户分页、角色分页、菜单树、通知列表均返回 `code = 200`。
- 参数：非法配置类型被拒绝，返回 `code = 400`，未写入数据。
- 权限：`operator`、`viewer` 访问用户管理接口均返回 HTTP 403；`viewer` 访问已授权数据大屏返回 HTTP 200。
