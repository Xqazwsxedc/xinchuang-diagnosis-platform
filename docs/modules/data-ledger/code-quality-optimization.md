# 数据台账模块代码打磨记录

日期：2026-07-27

## 打磨范围

- 后端：`apps/api-server/src/main/java/com/xinchuang/diagnosis/ledger/`
- 前端：`apps/admin-web/src/views/data-ledger/DataLedgerView.vue`
- 兼容性约束：不改变既有接口路径、请求/响应结构、数据库表映射和关联关系替换语义。

## 已完成优化

- 清理前端响应式表单中未使用的 `databaseId` 字段，同时保留接口请求载荷中的兼容字段。
- 数据库选项改为仅在打开业务系统新增或编辑抽屉时加载，减少页面初始请求。
- 后端服务复用对象查询方法，并为业务系统、数据库资源的新增、编辑、删除补齐事务边界。
- 补充正数 ID、关联数量、文本长度、状态白名单和严格 IPv4 地址校验。
- 保持业务系统分页列表的关联数据批量加载，避免恢复为 N+1 查询。
- 启动时精确同步 `admin`、`operator`、`viewer` 三个预置角色的默认权限；`viewer` 仅保留台账只读权限，自定义角色不受影响。

## 验证结果

- 后端编译：`scripts/build-api.ps1` 与 Maven `-DskipTests compile` 均通过。
- 前端构建：`scripts/build-web.ps1` 通过。
- 独立后端临时实例健康检查通过。
- `viewer`：台账查询返回 HTTP `200`；新增、删除返回 HTTP `403`。
- `operator`、`admin`：空保存请求返回业务码 `400`，未创建数据。
- 非法台账状态查询返回业务码 `400`；正常列表查询返回业务码 `200`。

- 前端新增入口改为统一抽屉，新增状态可通过顶部“业务系统 / 分布式数据库”页签切换；两个原有后端 CRUD 接口、表结构、权限编码和多对多关联保存逻辑均未修改。
