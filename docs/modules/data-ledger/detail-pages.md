# 数据台账详情页实现记录

日期：2026-07-29

## 范围

- 业务系统独立详情页：`/data-ledger/business-systems/:id`
- 分布式数据库独立详情页：`/data-ledger/db-resources/:id`
- 原列表页“查看详情”统一改为路由跳转；既有新增、编辑、删除接口和写权限保持不变。

## 数据与接口

- `bus_system_data_record`：业务数据收集时间、文件大小、状态、文件名和摘要。
- `db_instance_metric`：CPU、内存、磁盘 IOPS、缓存命中率和采样时间。
- `db_instance_log`：服务器日志时间、级别和内容。
- `report_export_log`：统一记录业务数据、数据库指标和数据库日志的 CSV 导出，台账扩展类型为 `BUSINESS_DATA`、`DB_METRICS`、`DB_LOG`。
- 全部查询与下载接口复用 `ledger:visualization:view`；下载同时记录操作日志。

## 页面实现

- 业务系统页按 Figma Make 原型展示标题返回、六项基础信息、业务数据库记录表、选中记录下载与单条下载；未选中记录时顶部下载按钮禁用。
- 数据库页按 Figma Make 原型展示四项基础信息、三张指标卡、时间范围切换、CPU/内存趋势、缓存命中率环图、日志页签和下载按钮；服务器日志支持勾选后下载。
- 两页统一使用 40px 内容区、浅蓝信息栏、12px 面板圆角、分段页签和交替表格行，并补齐窄屏单列布局。
- 数据库详情的“服务器指标 / 服务器日志”页签使用 flex 双向居中，不依赖默认行高，避免选中蓝色页签内文字偏移。
- 详情页具有加载、空数据、资源不存在、下载失败等状态反馈；列表进入详情时通过路由查询参数保留来源页签，点击详情标题返回后可恢复业务系统或分布式数据库列表。
- 2026-08-18 空数据渲染约束：服务器日志为空时不挂载 Element Plus 表格，只展示“当前时间范围暂无服务器日志”；指标无趋势点时不挂载四个趋势图和缓存圆环，只展示“暂无指标数据”。
- 2026-08-18 响应式约束：中等宽度（721-1300px）下数据库详情摘要和指标卡片使用两列，日志表在内容区内横向滚动，避免摘要与日志区域错位。

## 验证

- 后端 Maven 编译通过。
- 前端 `vue-tsc --noEmit` 与 Vite 生产构建通过。
- 隔离实例验证业务数据 4 条、数据库指标 15 条、日志查询、`1小时` 时间范围、CSV 下载和导出审计均正常。
- `admin`、`operator`、`viewer` 调用详情查询均返回业务码 `200`；非法指标范围返回业务码 `400`。
- 已在运行中的前端验证两条交互链路：业务系统列表 -> 详情 -> 业务系统列表、分布式数据库列表 -> 详情 -> 分布式数据库列表；返回后对应页签均处于选中状态。
- 当前源码隔离实例验证：选中一条业务记录或一条服务器日志时，CSV 均只导出一条数据，返回 `text/csv;charset=UTF-8`；后端 Maven 编译、前端生产构建和真实浏览器页面验收通过。
- 2026-08-18 `scripts/build-web.ps1` 通过；空态英文 `No Data`、指标空图表和中等宽度视觉回归需在登录态浏览器环境继续确认。

## 客户自配 Prometheus 监控配置（2026-08-18）

- 数据库详情页新增 Prometheus 监控状态、配置弹窗、保存配置和测试连接入口。
- 分布式数据库列表增加“监控状态”列；仅资源监控配置测试成功（`HEALTHY`）显示“已接入”，否则显示“未接入”，且当前数据状况显示“未知”。列表接口只返回脱敏的 `monitoringStatus`，不返回 Prometheus 凭据或认证内容。
- MySQL 配置必须同时填写 `nodeTargetSelector` 与 `databaseTargetSelector`；前者用于 CPU/内存/磁盘 IOPS，后者用于当前连接数/缓存命中率。
- 配置接口为 `GET/PUT /api/ledger/db-resources/{id}/monitoring-config` 和 `POST /api/ledger/db-resources/{id}/monitoring-config/test`；测试由 Spring Boot 服务端执行，前端不直连 Prometheus。
- 资源未配置或未测试通过时，指标接口不回退全局 target；Prometheus 异常仅显示在指标区域。
- 真实客户 Prometheus 的登录态浏览器验收和资源切换隔离验收仍待执行。
