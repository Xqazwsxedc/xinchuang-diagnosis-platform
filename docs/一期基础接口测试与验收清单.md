# 一期基础接口测试与验收清单

本文档用于“信创数据库智能故障诊断及修复平台”一期收尾验收。验收重点是确认系统可启动、可登录、权限真实生效、核心模块可完成基础 CRUD、AI 三大模块数据壳可演示。

## 1. 验收环境

项目路径：

```text
E:\vibe work\springboot work
```

后端地址：

```text
http://localhost:8080/api
```

前端地址：

```text
http://localhost:5173
```

默认账号：

```text
账号：admin
密码：password
```

数据库：

```text
xc_diagnosis
```

数据库脚本：

```text
apps/api-server/src/main/resources/schema.sql
apps/api-server/src/main/resources/data.sql
```

注意：

- 验收前先重启后端，让新增表、菜单权限和演示数据初始化生效。
- 验收前重新登录前端，刷新本地缓存的菜单和权限。
- AI 相关数据均为数据壳演示数据，名称、编码或内容中应包含“演示”或 `DEMO` 标识。

## 2. 启动验收

### 2.1 后端启动

执行：

```powershell
cd "E:\vibe work\springboot work\apps\api-server"
$env:JAVA_HOME="C:\Program Files\Java\jdk-17"
$env:MAVEN_HOME="E:\maven\apache-maven-3.9.16"
$env:Path="$env:MAVEN_HOME\bin;$env:JAVA_HOME\bin;$env:Path"

```

预期：

- 控制台无启动失败异常。
- 自动连接 MySQL。
- `schema.sql` 和 `data.sql` 执行成功。

```bash
curl http://localhost:8080/api/health
```

```json
{
  "code": 200
}
```

## 10. 基础接口冒烟测试

可使用同目录下的接口文件：

```text
docs/一期接口冒烟测试.http
```

建议执行顺序：

1. 登录获取 token。
2. 健康检查。
3. 当前用户。
4. 台账列表。
5. 数据大屏。
6. 通知未读数。
7. AI 模型、知识库、任务、结果列表。

核心预期：

- 所有成功接口返回 `code = 200`。
- 分页接口返回 `records`、`total`、`pageNo`、`pageSize`、`pages`。
- 未登录访问业务接口应返回 401。
- 无权限访问写接口应返回 403 或清晰无权限提示。

## 11. 一期不做范围

以下能力不作为一期验收失败项：

- 真实 AI 模型推理。
- 真实数据库指标采集。
- 自动诊断。
- 自动修复。
- 生产级高可用部署。
- WebSocket 实时推送。
- 多租户和复杂数据权限。
