# 前端页面集成验收清单 3.0

## 目的与环境

- 目的：覆盖 Vue 页面路由、抽屉、筛选、表单校验、权限按钮和下载/上传交互。
- 环境：本机开发或部署版；使用 `admin`、`operator`、`viewer` 三种既有账号。
- 原则：成功新增、编辑、删除、处理、上传仅在可回滚的隔离数据库进行；本机演示库只做只读及拒绝性验证。

## 系统与台账

| 编号 | 验收点 | 预期 |
|---|---|---|
| UI30-SYS-01 | 登录、退出、个人中心头像预览与资料校验 | 路由正确，敏感字段不回显，失败提示清晰。 |
| UI30-SYS-02 | 用户、角色、菜单、配置、字典、日志、通知 | 分页筛选与详情正常；无权限按钮隐藏或请求被拒绝。 |
| UI30-LEDGER-01 | 业务系统/数据库统一新增抽屉 | 顶部类型切换正确，必填和格式规则可见且生效。 |
| UI30-LEDGER-02 | 两类台账详情 | 演示数据、指标趋势、日志、记录下载入口可加载。 |

## AI 模块

| 编号 | 验收点 | 预期 |
|---|---|---|
| UI30-AI-01 | 故障、缺陷、优化三类知识库 | 类型隔离；附件选择、图片预览、其他文件下载、逻辑删除提示正确。 |
| UI30-AI-02 | 故障预测任务配置 | 对象二级联动、22 项指标全选/清空、每日/每周规则、详情抽屉和 PENDING 执行状态正确。 |
| UI30-AI-03 | 故障智能预警 | 抽屉包含故障 ID、预测对象、告警时间、指标类别、预测故障类型及处理历史。 |
| UI30-AI-04 | 缺陷检测任务与报表 | 任务详情、报表详情、筛选、导出和权限边界正确。 |
| UI30-AI-05 | 性能优化任务与建议 | 编辑不要求输入内部任务编码；任务执行显示等待引擎；建议详情与 CSV 导出正确。 |

## 记录方式

人工执行人必须在《测试用例执行明细-3.0》中填充实际日期、浏览器、账号和截图/录像证据路径；未执行项不得标记为通过。
