## 6. 风险与整改建议

| 优先级 | 风险 | 影响与建议 |
| --- | --- | --- |
| 已修复 | 管理员弱密码生成与重置行为 | 已移除硬编码弱密码和 SQL 演示管理员数据。仅当显式启用并提供 `BOOTSTRAP_ADMIN_PASSWORD` 时创建不存在的管理员，已有账号不会被修改。已有演示数据库中的管理员密码不会被自动改写，重启后须由管理员在个人中心完成一次密码修改。 |
| 已修复 | SQL 注入热点 | 兼容 DDL 改为固定白名单语句，SonarQube 热点为 0。 |
| 已修复 | `LedgerDownload` 数组相等性 | 保留 record 结构，并实现按字节内容比较、防御性复制和安全 `toString`，SonarQube Bug 为 0。 |
| P1 | 全项目覆盖率 8.4% | 新增代码已满足 81.3% 门禁，但存量系统管理、台账和 AI 服务仍需逐步提升至至少 60%。 |
| P2 | 重复行密度 20.0%、65 个代码异味 | 优先治理重复字符串和重复初始化数据；避免为了消除告警而改变现有权限、初始化或审计行为。 |
| P3 | 前端构建警告 | Sass legacy API、第三方 `PURE` 注释和单个压缩后包超过 500 kB 不阻断构建。后续可继续拆分入口包并升级依赖。 |
| P3 | SonarQube 默认管理员凭据 | 本机 SonarQube 启动日志仍提示默认管理员凭据。扫描使用临时令牌且已撤销；在多人或网络使用前必须修改 SonarQube 管理员密码。 |

## 7. 可复现命令

```powershell
# 后端单元测试、JaCoCo 报告
Set-Location apps/api-server
mvn verify

# 开发环境黑盒接口测试（需后端运行于 8080）
Set-Location ../..
./docs/testing/api-blackbox-test.ps1

# Windows 本机部署黑盒接口测试（经 Nginx）
./docs/testing/api-blackbox-test.ps1 -BaseUrl 'http://localhost/api' -ResultPath './docs/testing/results/deployment-api-blackbox-result.json'

# 前端构建
Set-Location apps/admin-web
pnpm build
```

SonarQube 扫描需要本机 SonarQube 服务和临时令牌。令牌不得写入源码、文档或版本库；扫描完成后应立即撤销。
