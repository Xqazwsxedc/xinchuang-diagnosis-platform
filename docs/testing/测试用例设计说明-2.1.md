# 测试用例设计说明 2.1

本版本以 `测试实施与质量报告-2.1.md` 和逐条机器结果为唯一执行结论。每个黑盒用例的 ID、步骤、接口、期望 HTTP 状态、实际状态、执行时间和通过结果均在 `results/api-blackbox-result-2.1.json`；每个白盒测试方法的类名、方法名、耗时和结果均在 `apps/api-server/target/surefire-reports/`。

| 分类 | 用例范围 | 典型场景 |
| --- | --- | --- |
| 认证安全 | WB-AUTH、WB-JWT、BB-BASE | 登录、Token、未认证、弱密钥 |
| 系统管理 | WB-BOOT、WB-SYS21、WB-NOTICE21、BB-SYS | 用户、头像、角色数据权限、配置、通知 |
| 数据台账 | WB-LEDGER、BB-LEDGER、WEB21-02~04 | 多对多关联、IPv4、详情、统一新增抽屉、权限 |
| 知识库 | WB-AI、BB21-AI-05、WEB21-05 | 空创建者、附件、下载、预览、逻辑删除 |
| 任务配置 | WB-AI、WB-AI21、BB21-AI-01~02、WEB21-06~07 | 指标、调度、任务编码、PENDING |
| 智能预警 | WB-AI、WB-AI21、BB21-AI-03~04、WEB21-08 | 查询、状态机、备注、删除权限 |
| 前端集成 | WEB21-01~09 | 菜单、权限按钮、抽屉、保存回显与原型布局 |

执行要求：先 `mvn verify`，再 SonarQube，再执行 `pwsh -File docs/testing/api-blackbox-test-2.1.ps1`，最后按 WEB21 清单人工验收。测试密码只能通过 `DIAGNOSIS_TEST_PASSWORD` 临时传入。
