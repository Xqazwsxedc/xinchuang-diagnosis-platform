# 数据库指标下载弹窗测试记录

## 1. 测试范围

本次覆盖数据库资源详情页“下载指标”弹窗、日期范围转换、指标白名单、CSV 列裁剪、监控接入校验和原有日志下载回归。实现文件为：

- 前端：`apps/admin-web/src/views/data-ledger/DbResourceDetailView.vue`
- 前端 API：`apps/admin-web/src/api/modules/ledger.ts`
- 后端 DTO：`apps/api-server/src/main/java/com/xinchuang/diagnosis/ledger/dto/DbMetricRangeQuery.java`
- 后端服务：`apps/api-server/src/main/java/com/xinchuang/diagnosis/ledger/service/impl/LedgerDetailServiceImpl.java`
- 时间范围：`apps/api-server/src/main/java/com/xinchuang/diagnosis/monitoring/prometheus/PrometheusRangeResolver.java`
- Prometheus 指标聚合：`apps/api-server/src/main/java/com/xinchuang/diagnosis/monitoring/prometheus/DbPrometheusMetricsService.java`

## 2. 白盒用例

| 编号 | 场景 | 预期 |
|---|---|---|
| BW-DL-01 | 日期下载按 Asia/Shanghai 转换开始时间 | 开始日 00:00 转为对应 UTC 时间 |
| BW-DL-02 | 结束日期包含当天 | 结束时间为结束日次日 00:00 |
| BW-DL-03 | 开始日期晚于结束日期 | 抛出“指标日期范围不合法” |
| BW-DL-04 | 仅传一个日期 | 抛出“开始日期和结束日期必须同时填写” |
| BW-DL-05 | 日期跨度超过 90 天 | 抛出“指标日期范围不能超过90天” |
| BW-DL-06 | 指标为空 | 抛出“至少选择一项指标” |
| BW-DL-07 | 指标包含未知编码 | 抛出“指标选择不合法” |
| BW-DL-08 | 只选择 CPU/内存/缓存命中率 | Prometheus 只查询选择项，CSV 仅输出对应列 |
| BW-DL-09 | 旧调用只传 `range` | 保持原八种相对范围下载兼容 |
| BW-DL-10 | 资源未接入监控 | 返回 409，禁止复用其他资源指标 |

代码用例：`apps/api-server/src/test/java/com/xinchuang/diagnosis/monitoring/prometheus/PrometheusRangeResolverTest.java`。

## 3. 前端与接口用例

| 编号 | 操作 | 预期 |
|---|---|---|
| BB-DL-01 | 点击“下载指标” | 打开“下载指标数据”弹窗，不立即发起下载 |
| BB-DL-02 | 使用最近 7/30/90 天、本月 | 开始和结束日期正确回填 |
| BB-DL-03 | 点击全选/清空 | 三项指标全部选中或全部清空 |
| BB-DL-04 | 清空指标后确认 | 确认按钮禁用，不能发起请求 |
| BB-DL-05 | 正常确认下载 | 请求携带 `startDate`、`endDate`、`metrics`，浏览器保存 CSV |
| BB-DL-06 | 后端返回错误 JSON | 页面显示后端具体错误信息，不下载错误响应 |
| BB-DL-07 | 服务器日志下载 | 原有勾选日志和 `range/logIds` 参数行为不变 |
